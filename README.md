# Nova Tools Hub

20 static browser tools. Open `index.html` locally or deploy the folder to GitHub Pages.

- Entry: `index.html`
- Tools: `tools/*.html`
- Styles: `assets/style.css`
- Shared helper: `assets/tool.js`
- SEO: each page has title/description/canonical/OG/Twitter/JSON-LD
- Ads: `#ad-top-banner`, `#ad-bottom-native`
- Sitemap: `sitemap.xml`

No build step required. All tool logic runs client-side. `qrcode.min.js` is vendored from the qrcode npm package for offline QR generation.
